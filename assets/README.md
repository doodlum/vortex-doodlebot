# Doodlebot artwork

The banner uses the tagline **Automated development & testing for Vortex**, with a compact
orange robot head, rounded corners and two rounded eyes.

- `doodlebot-banner.svg` and `doodlebot-banner.png`: charcoal banner, 1280 × 360.
- `doodlebot-banner-light.svg` and `doodlebot-banner-light.png`: light banner, 1280 × 360.
- `doodlebot-logo.svg` and `doodlebot.png`: standalone orange icon, 112 × 96, with transparency.
- `doodlebot-logo-mono.svg`: monochrome icon.

The SVGs contain editable geometry and outlined lettering, with no embedded raster images,
external fonts, scripts or network dependencies. The PNGs are direct renders of the SVGs.

The lettering uses [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope),
copyright 2018 The Manrope Project Authors, under the
[SIL Open Font License 1.1](OFL-Manrope.txt). The license is retained alongside the artwork.
