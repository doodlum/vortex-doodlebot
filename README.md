# Doodlebot

Doodlebot runs TypeScript tests and performance benchmarks against Vortex. It starts an isolated app, drives its UI, installs and deploys mods, and saves results you can compare between releases. Local tests need no Nexus account or installed game.

**[Read the documentation](https://doodlum.github.io/vortex-doodlebot/)** for installation, your first test, and the collection and table benchmark plan.

Requires Windows, a released Vortex installation, Node.js 20.19 or newer, and pnpm 9.15.0. No LLM is required.
